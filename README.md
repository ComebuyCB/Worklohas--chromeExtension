# Worklohas 擴充功能

## 功能說明

```
Worklohas 的便利工具。

1. 剪貼簿管理（Clipboard Manager）
  - 管理可快速複製的文字項目，支援群組分類與拖曳排序。

2. 網站注入開關
  - Popup 中，可個別開啟/關閉各網站的功能注入。

3. 測試帳密管理 (worklohas.com | worklohas.dev)
  - 偵測登入表單，自動儲存帳密並支援一鍵填入。

4. NUEIP 自動補卡（cloud.nueip.com）
  - 注入出勤紀錄補卡面板，一鍵補全所有缺卡記錄。
  - 可設定上下班目標時間 + 隨機浮動分鐘數。
  - 打卡時間設定值存於 chrome.storage。
  - 遲到請假試算。

5. Zoho Projects 介面（projects.worklohas.com）
  - 縮小詳細資訊面板，添加拖曳面板、置頂/置底 等功能。

6. 截圖標註工具（任意網站）
  - 由 Popup 按鈕或快捷鍵（預設 Alt+Z）開啟；開啟後在網頁上長按右鍵即可進入截圖模式。
  - 框選網頁任意區塊截圖，或截取整個網頁（含捲動範圍）。
  - 可在截圖上自由畫線、畫直線、箭頭、方框、加文字標註，提供 12 種畫筆顏色，支援復原／重做，並複製或下載圖片。
  - 截圖清單分「區塊」、「整頁」兩類，可放大編輯、切換上下張，清單寬度與排列方式可調整。
  - 可一鍵回到原網頁並標示截圖位置。
  - 截圖僅存於瀏覽器本機，不會上傳至任何伺服器。

==========================================================

▸ Google Sheets 說明
  - 使用者以 Google 帳號登入後，擴充功能自動在其 Google Drive
    建立名為 "Chrome Extension For Worklohas" 的試算表。
  - 剪貼簿資料存於 "ClipBoard" 分頁（欄位：標題、內容、群組、排序）。
  - 測試帳密管理存於 "Passwords" 分頁（欄位：網站、帳號、密碼、時間）。
  - 所有資料完全屬於使用者本人，擴充功能不經手任何第三方伺服器。
  - 透過 Google Sheets API 進行讀取、新增、更新、刪除操作。
```

## 要求權限的理由

| 權限 | 理由 |
|---|---|
| storage | 記下打卡時間、網站功能開關、個人設定，以及截圖工具的截圖與標註資料。 |
| clipboardWrite | 方便記錄常用文字，按下後複製內容；截圖工具也用於將截好的圖片、網址複製到剪貼簿。 |
| identity | Google OAuth 登入以存取 Google Sheets 剪貼簿資料、測試網站登入帳密。 |
| activeTab | 使用者按下 Popup 按鈕或快捷鍵時，擷取目前分頁的可見畫面以進行截圖標註。 |
| scripting | 使用者主動開啟截圖工具時，將工具介面注入目前分頁。 |
| unlimitedStorage | 截圖圖片（尤其整頁截圖）容量較大，容易超過預設的本機儲存上限；資料仍只存在使用者瀏覽器，不會上傳。 |
| debugger | 僅用於「整頁截圖」，與 Chrome 開發者工具「Capture full size screenshot」相同做法，暫時將頁面設為整頁尺寸以截取整個網頁；截完立即還原並中斷連線，不讀取、不修改網頁內容或網路請求。 |
| 網站存取權限 | 用於快速打卡 \| 公司測試站紀錄帳密 \| 網站不好用，簡易改樣式用途 \| 截圖工具需在使用者開啟的任意網頁上運作：開啟後長按右鍵截取畫面，並在同一分頁換頁後接回工具繼續截圖；未開啟截圖工具時，不會在其他網站注入程式或讀取內容。 |
